# The oracle still prints their first difference, as "known", but they do not fail the run. One "name reason" per line.
# Plain RC_DECOMP_FN functions get random pointers in random packets, so some inputs make them write (or read) an address

# wraps them into RAM. The same inputs differ in the live random test (checked 2026-11-13 with tools/shadow.sh, level 5,
# 100 inputs: identical iterations). No real call uses such an address.
